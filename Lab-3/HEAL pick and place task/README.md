# HEAL Pick-and-Place Report Bundle

This bundle is intended to be merged into the existing `Lab-3/HEAL/` project folder in the ITR repository.

## Included files

- `REPORT.md` — GitHub-rendered Markdown report with relative figure links.
- `README_HEAL.md` — this bundle note, so it does not overwrite an existing project README.
- `report/HEAL_Pick_and_Place_Report_5_pages.pdf` — fixed five-page submission copy.
- `report/HEAL_Pick_and_Place_Report_5_pages.docx` — editable copy.
- `report_assets/` — figures referenced by `REPORT.md`.

## Merge into the existing HEAL project

Copy `REPORT.md`, `README_HEAL.md`, `report/`, and `report_assets/` into the existing `Lab-3/HEAL/` folder. Merge the folders rather than replacing the existing `scripts/`, `scenes/`, `results/`, `plots/`, or robot asset folders. The Markdown report also documents paths to the project result CSVs and logs, which should be committed with the code.
